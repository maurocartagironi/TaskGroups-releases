# TaskGroups

Agrupá las ventanas abiertas en botones propios de la barra de tareas de Windows 11: hacés clic en el grupo y se despliega un menú vertical con sus ventanas.

## Descargar

Bajá `TaskGroups-Setup-X.Y.Z.exe` del [último release](https://github.com/maurocartagironi/TaskGroups-releases/releases/latest) y ejecutalo. Instala solo para tu usuario, sin pedir permisos de administrador.

Para actualizar: clic derecho en el ícono de TaskGroups en la bandeja → **Buscar actualizaciones** (también avisa solo cuando hay una versión nueva).

> Windows puede mostrar "Windows protegió su PC" porque el instalador no está firmado: **Más información → Ejecutar de todas formas**.

Este repositorio contiene solo los instaladores publicados.
